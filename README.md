# Pinnacle Fitness

Booking, membership, check-in and business platform for Pinnacle Fitness — a members-only coached gym at The Playground, 227 Western Main Rd, Port of Spain.

Next.js 16 · Tailwind v4 · Supabase · Wam payments · Resend · Vercel.

```bash
nvm use 22
npm install
cp .env.example .env.local   # Supabase, Wam, Resend, CRON_SECRET, NEXT_PUBLIC_SITE_URL
npm run dev
```

See `CLAUDE.md` for the design system, conventions and the layout of the app.
